# Student Management REST API

Node.js болон Express ашиглан хөгжүүлсэн Оюутны бүртгэлийн REST API төсөл.

##  Ажиллуулах заавар
1. `npm install`
2. `npm run dev`

Сервер `http://localhost:3000` дээр ажиллана.

##  API Endpoints
- `GET /api/v1/students` - Жагсаалт авах
- `GET /api/v1/students/:id` - Нэг оюутан авах
- `POST /api/v1/students` - Шинэ оюутан нэмэх
- `PUT /api/v1/students/:id` - Шинэчлэх
- `DELETE /api/v1/students/:id` - Устгах
